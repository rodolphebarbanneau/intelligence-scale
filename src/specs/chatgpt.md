# ChatGPT

## Product

ChatGPT is OpenAI's conversational AI assistant. People use it for everyday tasks such as brainstorming, writing, studying, planning, math, coding, and analyzing images or files. It follows instructions in a conversation and keeps context within a chat. The product is the ChatGPT chassis at chatgpt.com and in the ChatGPT apps. The model selected for a turn is part of that chassis.

This dossier is the Chat assistant. ChatGPT Work and Codex appear in the same product switcher. ChatGPT Workspace Agents is specified in `chatgpt-work`. Codex is specified in `codex`. Both are out of scope here.

People open ChatGPT on the web at chatgpt.com, including without an account in supported regions, or in the iOS and Android apps. The ChatGPT desktop app is available for macOS, Windows, and Linux. On the web and in the desktop app, a switcher above the composer selects Chat or Work. Chat is for a question or back-and-forth. Work is for a larger task with a reviewable result. Codex is the software-development surface.

A Chat session starts from a question, idea, notes, a file, or a task. The person can attach files, use web search, keep related work in a project, and install plugins. They review the result and ask for changes. ChatGPT remembers context within a chat. Follow-up questions continue that thread.

Plans documented across help and docs are Free, Go, Plus, Pro, Business, Edu, and Enterprise. Free is core ChatGPT with basic limits. Go is a lower-cost paid plan with higher limits than Free for eligible tools. Plus is $20 per month with broader model and tool access. Pro is a higher-tier personal plan. Business is a self-serve workspace that requires at least two Standard or Premium ChatGPT seats. Enterprise and Edu are managed workspace plans with admin controls. Feature availability depends on plan, platform, region, rollout, and workspace settings. A workspace administrator can control access to ChatGPT Work, plugins, browser use, and network access.

OpenAI may use content from personal ChatGPT accounts to improve models when Improve the model for everyone is on. By default it does not use content from ChatGPT Business, Enterprise, Edu, or ChatGPT for Healthcare workspaces to train models.

## Features

### Chat

Primary source: https://learn.chatgpt.com/docs/use-chatgpt.md

- ChatGPT is an AI agent that people communicate with in natural language. A first prompt does not need special commands.
- Chat is for a question or back-and-forth: ask a question, search the web, brainstorm, draft a message, or compare options.
- People start with a question, idea, notes, a file, or a task; ask ChatGPT to explain, develop, draft, research, analyze, or create; then add files, web search, projects, or plugins and refine the result.
- On the web and in the desktop app, a switcher above the composer selects Chat or Work. Codex is a separate choice in the product selector.
- Features depend on plan, platform, region, rollout, and workspace settings.
- ChatGPT is an AI assistant for everyday tasks such as brainstorming, writing, studying, planning, math, coding, and analyzing images or files. It is trained to follow instructions in a conversation. Source: https://help.openai.com/en/articles/12677804-what-is-chatgpt-faq
- Open ChatGPT, type in the message box, and send. Select New chat to start fresh. Source: https://help.openai.com/en/articles/12677804-what-is-chatgpt-faq
- ChatGPT remembers context within a chat. Follow-up questions continue that conversation. Source: https://help.openai.com/en/articles/12677804-what-is-chatgpt-faq
- ChatGPT understands natural language, follows complex instructions, remembers previous turns in a conversation, and adapts responses to context. Source: https://help.openai.com/en/articles/9260256-chatgpt-capabilities-overview
- People own output they create with ChatGPT, including the right to reprint, sell, and merchandise, subject to the Content Policy and Terms, on free or paid plans. Source: https://help.openai.com/en/articles/6783457-what-is-chatgpt

### ChatGPT on the web

Primary source: https://learn.chatgpt.com/docs/web.md

- ChatGPT on the web is at chatgpt.com. People sign in with a ChatGPT account.
- Select Chat for an answer or conversation. Select Work for research, analysis, documents, spreadsheets, presentations, Sites, and other multi-step tasks.
- Use a chat for a one-off task. Use a project to keep related chats, files, and instructions together.
- Install plugins to connect services such as Google Drive, GitHub, or Slack. Add skills when ChatGPT should follow a specific workflow.
- Select a model and reasoning level from the composer. Start with the default effort and increase it when a task needs deeper planning or analysis.
- In supported regions, people can try ChatGPT on the web without an account. Source: https://help.openai.com/en/articles/12677804-what-is-chatgpt-faq

- ChatGPT web keeps the authenticated session in the browser. On the desktop signed-out screen, select Continue to sign in, then complete the browser flow. Source: https://learn.chatgpt.com/docs/auth.md

### Projects and chats

Primary source: https://help.openai.com/en/articles/10169521-projects-in-chatgpt

- Projects group chats, uploaded reference files, and custom instructions under a shared objective. They are available to all free and paid subscription types. A person must be signed in.
- Create a project from New project in the sidebar. Name it and pick an icon and color.
- Project instructions apply only inside that project and override global custom instructions.
- Upload PDFs, spreadsheets, docs, or images, or paste text, as project sources. Only 10 files can be uploaded at the same time. Limits are Free 5 files per project; Go and Plus 25; Edu, Pro, Business, and Enterprise 40.
- Paste supported Google Drive (files and folders) or Slack (channels) links as project sources. Connect the app if prompted.
- Save a chat response to the project as a reusable source.
- Drag a chat onto a project, or use Move to project. Chats created with a GPT cannot be moved into a project. Temporary chats cannot be added to a project.
- Project tools include canvas, image generation, study mode, voice mode, and web search. Paid plans may also include agent mode and deep research.
- Users can create an unlimited number of projects. Access to projects is included with every qualifying ChatGPT plan.
- Project sharing is available to Free, Plus, Pro, and Go users globally on web, iOS, and Android, and to Business, Enterprise, and Edu workspaces.
- Invitees get edit or chat access. Edit can update instructions, upload or remove files, and invite others. Chat can see and use chats, files, and instructions.
- Free, Plus, Pro, and Go owners invite individuals. Business, Enterprise, and Edu owners can invite individuals or workspace groups, or share a workspace link. Collaboration limits include Free 5 collaborators, Plus and Go 10, Pro 100. Business, Enterprise, and Edu workspace projects are limited to 100 individuals and 40 files.
- Sharing a project turns memory to project-only. Shared projects do not use a member's memories or custom instructions from outside the project.
- Branch a chat to explore a new idea without losing the original thread. Branched chats appear in the project.
- The same project can contain chats started with Chat or ChatGPT Work. Source: https://learn.chatgpt.com/docs/projects.md
- Pin, rename, search, and archive chats and projects. Restore archived chats from Settings. Source: https://learn.chatgpt.com/docs/projects.md
- Apps in projects are supported for Free, Go, Plus, Pro, Business, Teachers, Enterprise, and Edu plans.

### Files and Library

Primary source: https://help.openai.com/en/articles/20001052-using-library-to-manage-files-in-chatgpt

- Library lets people find, reuse, download, and delete files uploaded to or created in ChatGPT, then add them to other conversations.
- Library is available to Free, Go, Plus, Pro, and Business users and to Enterprise, Edu, and Healthcare workspaces, including accounts in the EEA, Switzerland, and the United Kingdom.
- The full Library experience is on the web. Recent files in the composer and file search are also on iOS and Android.
- ChatGPT can save documents, spreadsheets, presentations, PDFs, and images. Generated images also appear in Images.
- Files uploaded in temporary chat are not saved to Library while the chat remains temporary. Files uploaded in ChatGPT Health are not saved to Library.
- When available, Library can show files and folders from connected Google Drive, Box, Dropbox, and SharePoint accounts. Connected files stay with the original service.
- Google Drive in Library supports Plus, Pro, Business, Enterprise, Edu, and Healthcare accounts on web, in both the Chat and Work toggles.
- Add a Library file from the composer menu with Add from library. A file added from Library stays in Library unless deleted separately.
- File size limits include 512 MB per file uploaded to a GPT or conversation, 2 million tokens per text or document file (not spreadsheets), about 50 MB for CSV and spreadsheet files, and 20 MB per image.
- Library storage limits are Free 500 MB, Go 4 GB, Plus and Business 20 GB, and Pro 100 GB. Library storage is separate from daily chat and attachment limits.
- A Library search setting in Settings > Personalization > Advanced controls whether ChatGPT automatically searches eligible Library files. Turning it off does not block manual browse, search, or attach.
- Workspace owners may control whether ChatGPT automatically references Library files. Automatic referencing is off by default for ChatGPT for Healthcare workspaces.
- Deleting a chat does not delete a file that remains in Library. OpenAI schedules deleted files for permanent deletion within 30 days unless it must retain them longer. Source: https://help.openai.com/en/articles/8983778-chat-and-file-retention-in-chatgpt
- On the desktop app, generated documents, presentations, spreadsheets, and PDFs can preview beside the chat. Annotations point at a part of a supported preview for a focused revision. Source: https://learn.chatgpt.com/docs/artifacts-viewer.md
- ChatGPT can summarize, extract information, or answer questions from uploaded PDFs, presentations, or plain text. Source: https://help.openai.com/en/articles/9260256-chatgpt-capabilities-overview

### Image generation and inputs

Primary source: https://learn.chatgpt.com/docs/image-generation.md

- Ask ChatGPT to generate or edit images from the composer. Attach a reference image to transform an existing asset or use it as visual guidance.
- Select a generated image to open an expanded viewer. Focused view inspects one image. Canvas view shows images generated in the same chat.
- In Canvas view, Comment adds feedback to one or more images. Multi-select chooses images, then send comments and editing instructions in the same chat.
- Image availability and usage limits on ChatGPT web depend on plan and workspace settings.
- Built-in image generation uses `gpt-image-2`. Image generations use included limits 3–5x faster on average than similar turns without image generation.
- Image generation is not available on the Free plan. Source: https://learn.chatgpt.com/docs/pricing.md

- Attach, paste, or drag an image into the ChatGPT web composer and say what to inspect and what result you want. Source: https://learn.chatgpt.com/docs/image-inputs.md
- ChatGPT can analyze uploaded images, diagrams, screenshots, or charts, generate images from text, and edit images with natural language. Source: https://help.openai.com/en/articles/9260256-chatgpt-capabilities-overview

### Web search

Primary source: https://learn.chatgpt.com/docs/web-search.md

- ChatGPT includes a first-party web search tool. Treat web results as untrusted input.
- On ChatGPT web, ask for current information or sources. Search results and citations appear in the chat when ChatGPT uses web search. Workspace settings can limit whether search is available.
- People can also click the web-search icon or use the `/Search` shortcut in supported experiences. Source: https://help.openai.com/en/articles/12677804-what-is-chatgpt-faq
- When Memory is enabled, ChatGPT may use relevant details to formulate a more useful search query. Source: https://help.openai.com/en/articles/8590148-memory-in-chatgpt

### Deep research

Primary source: https://help.openai.com/en/articles/9260256-chatgpt-capabilities-overview

- Deep research is designed for multi-step research. ChatGPT reads and synthesizes content across multiple online sources and produces cited, structured outputs.
- Deep research can work with uploaded files, search the public web or specific sites, and use enabled ChatGPT apps. ChatGPT creates a proposed research plan that the person can review and modify before research begins. Source: https://help.openai.com/en/articles/10500283-deep-research-in-chatgpt
- Deep research uses available read actions from connected apps. It does not use app write actions as part of research. Source: https://help.openai.com/en/articles/10500283-deep-research-in-chatgpt
- Usage varies by plan. An in-product usage counter shows remaining tasks. For plans with a fixed monthly allowance, it resets every 30 days from the date of first use. Source: https://help.openai.com/en/articles/10500283-deep-research-in-chatgpt
- On ChatGPT web, start a chat in Work, open the + menu, and select Deep research if it is available. Source: https://learn.chatgpt.com/docs/web-search.md

- Use it to summarize trends, clean data, or make projections.

### Canvas

Primary source: https://help.openai.com/en/articles/9930697-what-is-the-canvas-feature-in-chatgpt

- Canvas is an interface for writing and coding projects that need editing and revisions. Highlight a section to focus ChatGPT there. ChatGPT can give inline feedback with the whole project in mind.
- ChatGPT can open a canvas automatically when it generates content longer than about 10 lines or detects a writing or code scenario. People can also ask it to use canvas.
- Sharing a canvas is available for Free, Plus, Pro, Team, Enterprise, and Edu. Share a canvas asset such as rendered React/HTML, a document, or code from the canvas toolbar.
- Export documents to PDF, Markdown, or Word. Code canvases export in the detected language file extension.
- Canvas can be enabled as a capability on a GPT in the GPT Builder. The setting is off for existing GPTs and on by default for newly created GPTs.
- Canvas web preview can communicate with third parties. ChatGPT asks for confirmation before allowing that communication.

### Study mode

Primary source: https://help.openai.com/en/articles/11780217

- Study mode is available across ChatGPT plans globally on web, iOS, and Android, and works with any model available to the account.
- People can upload course materials, images, or PDFs. Study mode can reference those materials while helping them study.
- Study mode uses the same plan, model, message, and rate-limit rules as ChatGPT outside study mode. It does not add extra messages or bypass rate limits.
- If memory is available and enabled, ChatGPT may use saved memories or past chats to personalize study mode. Study mode still works when Memory is off.

### Voice

Primary source: https://help.openai.com/en/articles/20001274-chatgpt-voice

- ChatGPT Voice is a spoken conversation with ChatGPT. Options include Live, Advanced, and Standard.
- Live is powered by GPT-Live-1 on paid plans and GPT-Live-1 mini on Free. It can listen and speak at the same time, use web search and memory, show visual results through supported widgets, and work with text and images when those features are available.
- Live does not initially support video, screen sharing, connected apps, or plugins. Live cannot find or add files from Library. A supported file may still be attached manually.
- Advanced is the previous real-time Voice experience. Use it when you need supported mobile capabilities such as video or screen sharing.
- Standard is a turn-by-turn Voice experience that transcribes speech before generating a response.
- Audio clips from Live and Advanced, and video clips from Advanced, are stored with the transcript and retained for 30 days.
- Free, Plus, and Pro users in personal workspaces can share clips from Settings → Data Controls after turning on Improve the model for everyone and Include your audio recordings or Include your video recordings. Business, Enterprise, and Edu workspaces cannot share those clips.
- Live is not available with custom GPTs. Voice conversations with GPTs use Advanced Voice Mode and the Shimmer voice.
- In the ChatGPT desktop app, ChatGPT Voice is available with Plus, Pro, Business, Edu, and Enterprise. Enterprise and Edu availability begins with a two-week early-access period before the feature becomes available by default. Source: https://learn.chatgpt.com/docs/features/voice.md
- Desktop Voice can start work, check progress, or change direction in Chat, Work, and Codex. Only one voice chat can be active across the desktop app at a time. Source: https://learn.chatgpt.com/docs/features/voice.md
- Voice dictation turns speech into prompt text before sending. It is separate from ChatGPT Voice. Source: https://learn.chatgpt.com/docs/features/voice.md
- Voice mode is included on Go with the same usage limits as the Free tier. Source: https://help.openai.com/en/articles/11989085

### Memory and personalization

Primary source: https://help.openai.com/en/articles/8590148-memory-in-chatgpt

- When Memory is enabled, ChatGPT can remember relevant preferences and details from chats and other available sources. Features and controls vary by plan, region, platform, and workspace settings.
- Sources can include past chats, saved memories, custom instructions, files in Library, and content from connected apps such as Gmail.
- Manage Memory from Settings > Personalization > Memory. Turning Memory off does not delete past chats.
- The memory summary is a high-level view of information ChatGPT may use. People can correct it, select Don't mention this again, or Delete and turn off memory.
- Sources may appear below a response when ChatGPT uses personal context. Memory Sources are not included when a conversation is shared through a shared link.
- Reference chat history lets ChatGPT use relevant information from past conversations. Turning it off schedules that derived information for deletion within 30 days. Original chats remain unless deleted.
- Saved memories are stored separately from chat history. Deleting the original chat does not automatically delete a saved memory.
- Improved Memory updates a broader summary of relevant context. Legacy saved memories use an explicit list of items. People can switch between the experiences where the option is available.
- In ChatGPT for Healthcare and ChatGPT Enterprise with Regulated Workspace, improved memory is disabled by default. The feature is not covered under a BAA.
- Custom instructions are direct guidance about what ChatGPT should know and how it should respond. Memory can use information that develops across conversations.
- Choose Friendly, Pragmatic, or None as the default personality in Settings > Personalization. A personality changes how ChatGPT communicates, not what the model can do. Source: https://learn.chatgpt.com/docs/personalize.md
- Use custom instructions for preferences to follow across chats, such as response style. Source: https://learn.chatgpt.com/docs/personalize.md
- Memory is not currently available in custom GPTs. Source: https://help.openai.com/en/articles/9260256-chatgpt-capabilities-overview
- GPTs do not use saved memory, custom instructions, or previous conversations. Each GPT conversation starts fresh. Source: https://help.openai.com/en/articles/8554407-gpts-in-chatgpt

### GPTs

Primary source: https://help.openai.com/en/articles/8554407-gpts-in-chatgpt

- GPTs are versions of ChatGPT configured for a specific purpose. A GPT can combine instructions, knowledge, and selected capabilities.
- Signed-in users can use public GPTs, GPTs shared with them, or GPTs available through workspace settings. Public GPT pages may be visible without signing in; chatting requires sign-in.
- New GPT creation and publishing are not available on personal ChatGPT accounts, including Free, Go, Plus, and Pro. Existing GPTs remain usable. Editing still requires an eligible subscription and permissions.
- In Business, Enterprise, and Edu workspaces, creation, editing, and publishing depend on workspace settings and permissions.
- OpenAI plans to retire custom GPTs and move workflows to plugins. For affected Enterprise workspaces, retirement is planned for 11 December 2026. A migration experience is targeted for 17 September 2026 and may not be available to every account at the same time.
- A GPT can include instructions, conversation starters, knowledge files, capabilities such as web search or image generation, apps, and actions. A GPT can use either apps or actions, not both.
- Open Explore GPTs in ChatGPT, use a direct link, or open a GPT shared in the workspace.
- On ChatGPT web, type `@` in a conversation to bring in a GPT without starting a new chat. The conversation keeps its current context.
- GPT builders cannot view individual conversations that users have with their GPTs.
- Create a GPT at https://chatgpt.com/gpts with a conversational builder or the configuration view. Creation and editing are on the web. Source: https://help.openai.com/en/articles/8554397-creating-and-editing-gpts
- Attach up to 20 knowledge files to a GPT, each up to 512 MB. Capabilities can include web search, image generation, canvas, Code Interpreter & Data Analysis, and apps. Source: https://help.openai.com/en/articles/8554397-creating-and-editing-gpts
- Changes save to a draft. Version history can review and restore earlier versions. Source: https://help.openai.com/en/articles/8554397-creating-and-editing-gpts

### Skills and plugins

Primary source: https://learn.chatgpt.com/docs/skills-and-plugins.md

- A skill packages instructions and supporting resources for a specific task or workflow. A plugin is an installable bundle that can include skills and MCP servers.
- ChatGPT can choose a skill when a request matches its purpose, or the person can select one with `@`.
- Build a skill in ChatGPT with `@skill-creator`. Review the draft, test it, then install and reuse it. Share it when workspace settings allow.
- Plugins work in Chat and Work across ChatGPT on the web, desktop, and mobile. Desktop-only plugins must be installed in the desktop app. Source: https://learn.chatgpt.com/docs/plugins.md
- ChatGPT and Codex use one universal plugin directory. Tabs include OpenAI, the workspace name, and Personal. Source: https://learn.chatgpt.com/docs/plugins.md
- After installation, start a new chat and ask ChatGPT to use the plugin, or type `@` to invoke the plugin or a bundled skill. Source: https://learn.chatgpt.com/docs/plugins.md
- Sign in with ChatGPT is rolling out in beta for supported plugins and partner sites, including Airtable, GitLab, HubSpot, Notion, Supabase, and Vercel. Signing in shares name, email, and profile picture when available. It does not grant the plugin access to data or approve actions. Source: https://learn.chatgpt.com/docs/plugins.md
- An app connects ChatGPT to an external service. A plugin can include one or more apps, skills, or both. Installing a plugin does not bypass app authorization or workspace permissions. Source: https://help.openai.com/en/articles/11487775-connected-apps-in-chatgpt

### Connected apps

Primary source: https://help.openai.com/en/articles/11487775-connected-apps-in-chatgpt

- Apps connect ChatGPT to services such as Google Drive or Slack so people can find a file, summarize a document, look up a message, use in-chat experiences, or take supported actions.
- App availability depends on the app, plan, region, workspace, role, model, and interface.
- Connect an app from Settings > Plugins. Review requested permissions and complete provider authorization. Some apps use an administrator-managed connection.
- In a conversation, mention an app or plugin with `@`, or select + and choose it. ChatGPT may ask for approval before reading information or completing an action.
- Permission options may include Always ask, Allow read actions, Allow low-risk actions, and Allow all actions for an eligible app. Changing a permission only changes when ChatGPT asks; it does not grant new access.
- In ChatGPT Business, many apps are enabled by default. New Enterprise and Edu workspaces start with a selected set of enabled apps. User conversations that use apps are available in the Compliance API.
- Documented provider setup articles include Google Drive, SharePoint, Microsoft Teams, Outlook Email and Calendar, Slack, GitHub, GitLab, Box, and Notion.
- For Free, Plus, Go, and Pro, OpenAI may use information accessed from apps to train models if Improve the model for everyone is on. Business, Enterprise, and Edu do not use connector information to train models by default.

### Scheduled tasks

Primary source: https://learn.chatgpt.com/docs/automations.md

- Schedule recurring tasks to run in the background. Review active, paused, and completed tasks and recent runs in Scheduled.
- When scheduled tasks are enabled for the workspace, create them from Chat or ChatGPT Work on the web. Web tasks can use uploaded context and connected tools. They cannot work directly in a folder on a computer.
- Use a standalone scheduled task when each run should start from the saved prompt. Use a scheduled task in a chat when ChatGPT should return to the same chat with existing context.
- On eligible plans, scheduled tasks on web and mobile can run when a supported Gmail, Slack, or GitHub event occurs. Event-triggered tasks are not available in the ChatGPT desktop app. One task cannot combine event triggers with a time-based schedule.
- Supported event triggers include Gmail incoming messages (optionally filtered by sender or subject), Slack messages in selected channels, and GitHub pull request activity. For Slack, add `@ChatGPT` to every watched channel.
- In managed workspaces, administrators can control access with Allow event-triggered scheduled tasks.
- Ask ChatGPT to create or update a scheduled task from a chat. Describe the work, when it should run, and whether each run should return to the current chat or start a new chat.
- Active task limits vary by plan: Go 3, Plus 5, Business and Edu 10, Pro and Enterprise 15. Tasks are supported by all ChatGPT models except Pro models. Source: https://help.openai.com/en/articles/10291617
- In the desktop app, select ChatGPT from the top-left menu, then Scheduled in the sidebar. Scheduled is not available in Codex. Source: https://help.openai.com/en/articles/10291617

### Sites

Primary source: https://learn.chatgpt.com/docs/sites.md

- Sites is in public beta and is available with Plus, Pro, Business, Enterprise, and Edu. Plan-specific usage limits apply during the beta.
- Sites lets ChatGPT create, host, refine, and share websites, web apps, and games. A Site is separate from a ChatGPT Project.
- On the web, select More > Sites or go to chatgpt.com/sites. Include the word website in a prompt or mention `@Sites` to start the workflow.
- Every Sites deployment URL is a production deployment. Ask ChatGPT to save a version without deploying it to review a build first.
- A new Site is limited to its owner and workspace admins until access changes. Sharing options can include owner and admins, selected users or groups, invited external viewers, anyone in the workspace, or anyone on the internet when public publishing is enabled.
- In Enterprise workspaces, public publishing is off by default. External invitations are rolling out to Plus, Pro, Business, and Enterprise.
- Public Sites can offer optional Sign in with ChatGPT. After sign-in, Sites forwards identity through `oai-authenticated-user-email` and optional `oai-authenticated-user-full-name`.
- Site owners can change the ChatGPT-hosted URL where URL editing is available. Custom domains are a separate feature and are not available in Enterprise workspaces at launch.
- Each Site has a 10 GB D1 database storage limit. R2 object storage has no fixed storage limit. Sites does not support data residency or inference residency at launch.
- Analytics for unique visitors and page views is currently available for Sites that are not owned by an Enterprise workspace.

### Visualizations

Primary source: https://learn.chatgpt.com/docs/visualizations.md

- Visualizations turn questions, ideas, and information into charts, maps, diagrams, calculators, simulations, and interactive explanations in a ChatGPT chat.
- The Visualizations preview is rolling out. Availability can depend on plan, platform, account, and workspace settings.
- On ChatGPT web, Visualizations are available to supported accounts in Chat and ChatGPT Work. Type `@` and select Visualize under Plugins, or type `@Visualize`.
- Rendering is not supported in Codex CLI or the IDE extension. Desktop and mobile availability is rolling out.
- Use the chat's Share action when available. A visualization is generally a snapshot of the information available when ChatGPT created it, not a live dashboard.

### Sharing, temporary chat, and history

Primary source: https://help.openai.com/en/articles/12677804-what-is-chatgpt-faq

- Use Share to create a link to a read-only copy of a conversation.
- A link created in a Business, Enterprise, Edu, or Healthcare workspace can be opened only by eligible members of the same workspace. A workspace conversation link can include messages added after sharing. Source: https://help.openai.com/en/articles/7925741-sharing-conversations-and-scheduled-tasks-in-chatgpt
- Enterprise and Edu admins can manage Share chats and scheduled tasks from Workspace settings > Permissions & roles. Business links are restricted to the originating workspace. Business does not provide the same workspace-wide control for disabling shared links. Source: https://help.openai.com/en/articles/7925741-sharing-conversations-and-scheduled-tasks-in-chatgpt
- Temporary chats do not show in history, do not create or update memories, and are not used to train models while they remain temporary. Start a temporary chat from the model menu. Source: https://help.openai.com/en/articles/8914046-temporary-chat-in-chatgpt
- Before a temporary chat begins, choose Personalized or Unpersonalized. Personalized temporary chats can use existing memories, custom instructions, and plugins. The choice cannot be changed after the chat starts. Source: https://help.openai.com/en/articles/8914046-temporary-chat-in-chatgpt
- Saving a temporary chat converts it to a regular chat. OpenAI may retain a copy of an unsaved temporary chat for up to 30 days for safety purposes. Source: https://help.openai.com/en/articles/8914046-temporary-chat-in-chatgpt
- Regular and archived chats remain saved until deleted or until a workspace retention policy removes them. Archiving does not change the retention period. Source: https://help.openai.com/en/articles/8983778-chat-and-file-retention-in-chatgpt
- People can view and continue past conversations. Source: https://help.openai.com/en/articles/6783457-what-is-chatgpt

### Notifications

Primary source: https://learn.chatgpt.com/docs/notifications.md

- On the web, Settings > Notifications manages notification categories and channels. Channels can include push, email, or SMS depending on the category and account.
- On the desktop app, Settings chooses whether turn-completion alerts appear never, only while ChatGPT is in the background, or always. Separate controls turn permission and question notifications on or off.
- When Activity is available, select the bell in the sidebar to see chats that are unread, running, or waiting for a response. Options can include Work, Chat, Pinned, and Scheduled.

### Pets

Primary source: https://learn.chatgpt.com/docs/pets.md

- Pets are optional animated companions. Choosing a pet changes appearance, not how ChatGPT completes tasks.
- On the desktop app for macOS and Windows, a pet can float above other windows. Use it to start a chat by typing or speaking and to follow activity.
- Default shortcuts are Option+Space on macOS and Windows+Alt+P on Windows. Status values are Running, Needs input, Ready, and Blocked.
- On the web, if Pets are available, open Settings > Personalization > Pet > Select pet. A web pet appears inside supported ChatGPT Work chats.

### Plans and billing

Primary source: https://learn.chatgpt.com/docs/pricing.md

- ChatGPT Work and Codex share usage. ChatGPT Work usage inside ChatGPT uses the same pricing, credits, and usage limits as Codex.
- Documented plans include Free, Go, Plus, Pro, Business, Edu, and Enterprise. ChatGPT Work and Codex are included in those plans.
- Plus includes other ChatGPT features as part of the Plus plan. Pro includes 5x or 20x more Codex usage than Plus and other ChatGPT features as part of the Pro plan.
- Business includes a dedicated workspace with essential admin controls, SAML SSO, and MFA, and no training on business data by default.
- Enterprise includes priority request processing, SCIM, EKM, user analytics, domain verification, RBAC, audit logs and usage monitoring via the Compliance API, and data retention and data residency controls.
- Message limits vary by plan and model and can change over time. Plus has higher limits than Free. Business and Enterprise have higher limits than Plus. Source: https://help.openai.com/en/articles/12677804-what-is-chatgpt-faq
- ChatGPT Go provides higher limits than Free for eligible features such as image generation, file uploads, and data analysis. Voice mode on Go uses the same usage limits as Free. Subscriptions are billed monthly. Source: https://help.openai.com/en/articles/11989085
- ChatGPT Plus is $20 per month and provides enhanced access to the ChatGPT web app and supported apps. API usage is billed separately. Source: https://help.openai.com/en/articles/6950777
- Plus and Pro users who reach a usage limit can purchase additional credits. Business, Edu, and Enterprise plans with flexible pricing can purchase additional workspace credits. Source: https://learn.chatgpt.com/docs/pricing.md
- Sites is included with eligible ChatGPT plans during public beta. Voice in Desktop uses the existing Codex usage budget at $0.05 per minute, or 1.25 credits per minute for Business, Edu, and Enterprise workspaces with credit-based billing. Source: https://learn.chatgpt.com/docs/pricing.md

### Business, Enterprise, and Edu

Primary source: https://help.openai.com/en/articles/8792828-chatgpt-business-overview

- ChatGPT Business is a self-serve workspace plan for organizations. A seat is paid capacity separate from the member who uses it.
- Standard ChatGPT seats include ChatGPT, ChatGPT Work, and Codex, as well as GPTs, Projects, Apps, Company Knowledge, ChatGPT Agent, and Deep Research.
- Premium ChatGPT seats include the same access as Standard with higher usage limits. Premium costs $100 per user per month billed annually, or $125 billed monthly, and includes 5x more usage than Standard.
- A Business workspace can mix Standard and Premium seats. It requires two Standard or Premium ChatGPT seats.
- ChatGPT Team was renamed to ChatGPT Business on 29 August 2025.
- ChatGPT Business is separate from the API platform. API usage is billed independently. OpenAI does not train on Business workspace data.
- ChatGPT Enterprise is a managed plan with enterprise-grade privacy and security, centralized member management, domain verification, SSO, SCIM, and usage insights. Source: https://help.openai.com/en/articles/8265053-what-is-chatgpt-enterprise
- Enterprise and Edu workspaces have ChatGPT seats and Codex seats. A Codex seat does not include ChatGPT access. Source: https://help.openai.com/en/articles/8265053-what-is-chatgpt-enterprise
- In a Business workspace, each user has their own chat history. Other members do not automatically see those chats. Shared links are for members of the same workspace. Source: https://help.openai.com/en/articles/8798634
- Workspace owners and admins can manage supported memory settings and role permissions. Source: https://help.openai.com/en/articles/8590148-memory-in-chatgpt
- Projects inherit workspace toggles. If deep research, voice mode, memory, or another feature is disabled at the workspace level, it is disabled inside every project. Source: https://help.openai.com/en/articles/10169521-projects-in-chatgpt
- Some ChatGPT and Codex features ship with a maturity label: Under development, Experimental, Beta, Stable, or Deprecated. Source: https://learn.chatgpt.com/docs/feature-maturity.md

### Data controls and privacy

Primary source: https://help.openai.com/en/articles/7039943-how-openai-handles-data-in-consumer-services

- In ChatGPT, open Settings and select Data controls to manage model-improvement preferences and other data controls. Memory settings are in Settings > Personalization.
- OpenAI may use content submitted to personal ChatGPT accounts to improve models when that setting is on. By default it does not use content from Business, Enterprise, Edu, ChatGPT for Healthcare, or the API Platform to improve models.
- Export data from Settings → Data Controls → Export. Delete an account in Settings or via the Privacy Portal. Source: https://help.openai.com/en/articles/12677804-what-is-chatgpt-faq
- If an account is fully deleted rather than deactivated, the same email can create a new account after 30 days.
- Cleared chats are deleted from OpenAI systems within 30 days, unless they were previously de-identified or must be kept for security or legal reasons.
- OpenAI does not sell data or share ChatGPT conversations with advertisers.
- Submit a privacy request through the Privacy Portal or email dsar@openai.com.

### Models

Primary source: https://learn.chatgpt.com/docs/models.md

- GPT-5.5 retires from ChatGPT, ChatGPT Work, and Codex on all plans on 14 October 2026. The OpenAI API is not affected.
- In ChatGPT, GPT-6 Sol and GPT-6 Luna are available in Work and Codex. They are not available in Chat.
- Paid-plan customers can choose between several foundational models. Source: https://help.openai.com/en/articles/9260256-chatgpt-capabilities-overview
- Replace `gpt-5.5` in workspace defaults, saved model settings, managed configurations, custom agents, scheduled tasks, and scripts that select a model before 14 October 2026.
